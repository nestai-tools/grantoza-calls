# Q-123 — Małe i średnie przedsiębiorstwa wprowadzające innowacje produktowe lub procesowe / Nazwa i opis

[Formularz / szablon odpowiedzi](../indicators.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Jednostka: przedsiębiorstwa; nie sumuj podwójnie tej samej firmy wprowadzającej oba rodzaje. Podaj definicję, źródło danych, metodę i termin potwierdzenia.

Warunek: zawsze. Typ: tekst. Limit znaków: 1000.

Wybory: nie dotyczy.

Wymagania: REQ-020, REQ-031
