# Q-051 — Adres prowadzenia działalności / Numer lokalu

[Formularz / szablon odpowiedzi](../applicant.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Podpole adresu wskazanego we wzorze; zachowaj zgodność z rejestrem. Numer lokalu tylko gdy występuje. Wzór nie określa odrębnego limitu znaków.

Warunek: gdy adres prowadzenia działalności różni się od siedziby. Typ: tekst. Limit znaków: None.

Wybory: nie dotyczy.

Wymagania: REQ-002, REQ-006, REQ-007, REQ-027
