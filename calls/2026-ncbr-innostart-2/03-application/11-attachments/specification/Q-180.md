# Q-180 — 5. Kopia zaświadczeń de minimis / rolnictwo / rybołówstwo (w okresie 3 lat)

[Formularz / szablon odpowiedzi](../attachments.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Ruchomy okres 3 lat przed złożeniem. Przy braku zaświadczeń dokumenty dopuszczają wykazanie pomocy w oświadczeniu.

Warunek: gdy posiadane są zaświadczenia o otrzymanej pomocy. Typ: zalacznik. Limit znaków: None.

Wybory: nie dotyczy.

Wymagania: REQ-003, REQ-004, REQ-005, REQ-006, REQ-007, REQ-014, REQ-022, REQ-027
