# Q-077 — Rozwiązania wspierające zieloną gospodarkę

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Opcjonalny dodatkowy punkt kryterium 14. „Nie dotyczy” wybierz samodzielnie, bez innych opcji.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: zmniejszanie emisji zanieczyszczeń, zmniejszanie energochłonności, zmniejszanie zużycia wody, wykorzystanie materiałów (odpadów) pochodzących z recyclingu, wykorzystanie odnawialnych źródeł energii, nie dotyczy.

Wymagania: REQ-014
