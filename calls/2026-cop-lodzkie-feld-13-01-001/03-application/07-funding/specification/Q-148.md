# Q-148 — Budżet państwa — wydatki kwalifikowalne (PLN)

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Własne środki z danego źródła; do 2 miejsc po przecinku. Wpisz 0, jeżeli źródło nie uczestniczy. Źródła muszą pokrywać cały wkład własny, w tym koszty niekwalifikowalne.

Warunek: zawsze. Typ: liczba. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-006, REQ-007, REQ-008, REQ-020, REQ-028.
