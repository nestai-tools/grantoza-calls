# Q-054 — Wartość docelowa — Mężczyźni

[Formularz / szablon odpowiedzi](../output-indicators/_template.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Wartość zgodna z definicją, jednostką i realnymi założeniami. Przy podziale suma kobiet i mężczyzn równa ogółem. Dla rezultatu bazą zwykle 0 — sprawdź definicję; nie wpisuj automatycznie.

Warunek: Podział na płeć = Tak. Typ: liczba. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-015, REQ-027.
