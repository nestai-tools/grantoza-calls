# Q-203 — 18. Porozumienie / umowa o partnerstwie / konsorcjum

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

W partnerstwie wymagane porozumienie lub list intencyjny z umocowaniem lidera na etapie aplikowania; pełna umowa przed umową dotacji. Jeden plik na pozycję w WOD2021, maks. 25 MB; kilka dokumentów scal lub spakuj. Świadome oznaczenie późniejszego dołączenia jest planem, nie potwierdzeniem złożenia ani poprawności dokumentu.

Warunek: Partnerstwo/konsorcjum. Typ: zalacznik. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-018, REQ-019, REQ-020, REQ-021, REQ-022, REQ-023, REQ-024, REQ-025, REQ-026.
