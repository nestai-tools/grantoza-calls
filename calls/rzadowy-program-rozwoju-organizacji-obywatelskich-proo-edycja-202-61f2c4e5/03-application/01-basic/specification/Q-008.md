# Q-008 — Rodzaj zadania publicznego

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Powierzenie przy braku wkładu własnego, wsparcie przy planowanym wkładzie. Wydatki inwestycyjne wymagają min. 10% wartości wydatku z własnych środków finansowych.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: Powierzenie (brak wkładu własnego), Wsparcie (planowane wniesienie wkładu własnego).

Wymagania: REQ-012
