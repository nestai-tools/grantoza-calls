# Q-183 — pobieranie świadczeń pieniężnych od odbiorców zadania będzie się odbywać wyłącznie w ramach prowadzonej odpłatnej działalności pożytku publicznego (tylko Oferenci, którzy w ofercie zaplanują pobieranie wpłat i opłat od adresatów zadania) ;

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: Tak, Nie, Nie dotyczy.

Wymagania: REQ-001, REQ-028, REQ-029
