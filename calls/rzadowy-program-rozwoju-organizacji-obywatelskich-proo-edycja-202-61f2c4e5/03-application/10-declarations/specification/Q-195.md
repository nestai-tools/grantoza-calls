# Q-195 — Czytelny podpis osoby upoważnionej

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Czynność podpisania wymaganego dokumentu przez osobę uprawnioną. Nie twórz podpisu ani potwierdzenia jego złożenia. Samą ofertę wysyła się elektronicznie w SOD.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: Zgodność z instrukcją pola.

## Źródła
