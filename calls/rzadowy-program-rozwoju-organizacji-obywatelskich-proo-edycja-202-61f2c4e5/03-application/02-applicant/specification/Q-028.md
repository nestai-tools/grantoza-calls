# Q-028 — Gmina

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Dane zgodne z rejestrem. W zrzucie SOD pole pobierane z profilu organizacji i zablokowane do edycji; w lokalnym wniosku zachowano miejsce przygotowania danych. Zmiany wprowadź także w profilu SOD. Słownik zależny od województwa/powiatu; zrzut zawiera tylko wybrany fragment, dlatego nie ograniczono lokalnego wyboru do jednej lokalizacji. Wartość dopasuj w SOD.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-001, REQ-029
