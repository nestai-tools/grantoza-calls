# Q-013 — Forma prawna

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Dane zgodne z rejestrem. W zrzucie SOD pole pobierane z profilu organizacji i zablokowane do edycji; w lokalnym wniosku zachowano miejsce przygotowania danych. Zmiany wprowadź także w profilu SOD.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: Fundacja, Stowarzyszenie, Spółdzielnia socjalna, Klub sportowy, Kościół / związek wyznaniowy, Spółka akcyjna / spółka z ograniczoną odpowiedzialnością, Inny podmiot.

Wymagania: REQ-001, REQ-029
