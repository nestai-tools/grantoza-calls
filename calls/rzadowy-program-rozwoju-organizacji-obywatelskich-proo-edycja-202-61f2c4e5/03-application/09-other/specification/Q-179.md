# Q-179 — Inne działania i informacje istotne przy ocenie oferty

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Uzasadnij kalkulację kosztów, ceny rynkowe, rozdzielenie źródeł, finansowy wkład min. 10% każdego wydatku inwestycyjnego oraz kwestie VAT i oświadczeń, jeśli dotyczą zadania. Informacje muszą odpowiadać danym w budżecie.

Warunek: zawsze. Typ: opis. Limit znaków: 10000.

Wybory: nie dotyczy.

Wymagania: REQ-012, REQ-015, REQ-016, REQ-017, REQ-018, REQ-028
