# Dokumenty i załączniki — PROO 1a 2027

W dostarczonych zrzutach PROO 1a 2027 nie ma sekcji uploadu ani listy obowiązkowych załączników przy wysyłce oferty. Ogólne stwierdzenie w ogłoszeniu o ocenie wniosku „wraz z załącznikiem” nie identyfikuje konkretnego dokumentu 1a. Nie dodano fikcyjnego obowiązkowego pola pliku.
