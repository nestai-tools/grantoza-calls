# Q-020 — Potencjał rynkowy i skalowanie

## Wskazówki

Opisz potencjał rynkowy i możliwość skalowania rozwiązania

Opisz odbiorców, problem, model biznesowy, potwierdzoną walidację i sposób skalowania. Nie przedstawiaj niepotwierdzonych prognoz jako faktów.

Limit długości nie jest widoczny na zrzutach. Sprawdź komunikaty portalu przed wysłaniem.

Warunek: zawsze — pole oznaczone gwiazdką w F6S. Typ: opis. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-013
