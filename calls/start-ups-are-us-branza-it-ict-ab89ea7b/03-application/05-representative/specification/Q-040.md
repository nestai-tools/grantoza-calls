# Q-040 — Stanowisko lub funkcja przedstawiciela

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Funkcja potwierdzająca właściwą kategorię przedstawiciela; sam wpis nie dowodzi umocowania. RNU określa odrębne zasady zmiany osoby przed rozmową, a umowa przed misją.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-012, REQ-027, REQ-035
