# Q-036 — Imię przedstawiciela

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Osoba uprawniona i ujawniona w CEIDG/KRS zgodnie z definicją. Dopuszczalne kategorie: przedsiębiorca indywidualny; wspólnik spółki jawnej lub komplementariusz; członek organu zarządzającego lub prokurent spółki; członek organu zarządzającego innej uprawnionej jednostki. Nie dodawać innych osób jako kolejnych przedstawicieli.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-012, REQ-027
