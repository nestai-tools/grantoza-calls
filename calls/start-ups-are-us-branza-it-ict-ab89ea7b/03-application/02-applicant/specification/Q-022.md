# Q-022 — Adres e-mail wnioskodawcy

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Aktualny adres e-mail zapewniający skuteczną komunikację. Adres właściciela konta LSI pozostaje również obowiązkiem komunikacyjnym z RNU, bez dodatkowego pola we wzorze.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-013, REQ-026
