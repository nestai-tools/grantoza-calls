# Q-007 — Data rozpoczęcia działalności zgodnie z dokumentem rejestrowym

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

KRS: data rejestracji; CEIDG: data rozpoczęcia wykonywania działalności. Panel zapisuje ISO, instrukcja podaje RRRR/MM/DD. Nie utożsamiać automatycznie daty rozpoczęcia CEIDG z datą rejestracji do kryterium wieku. Nie obliczać wieku bez właściwej daty rejestracji, złożenia i rozstrzygnięcia rozbieżności dokumentów.

Warunek: zawsze. Typ: data. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-003, REQ-013
