# Q-024 — Adres do e-Doręczeń

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Własny adres do e-Doręczeń służący korespondencji według RNU. Nie wpisywać adresu PARP. Dokumentacja formularza nie opisuje odrębnej opcji dla braku adresu.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-013, REQ-026
