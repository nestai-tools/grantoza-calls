# Q-009 — Forma własności

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Wybór pojedynczy zgodny z REGON. Pełnego słownika nie dostarczono; możliwy ręczny wpis kodu/nazwy z późniejszym dopasowaniem do LSI. Instrukcja wskazuje dla osoby fizycznej prowadzącej działalność wartość „Krajowe osoby fizyczne”, w pozostałych opisanych przypadkach „Pozostałe krajowe jednostki prywatne”. Nie przedstawiono tych wskazań jako pełnej listy portalu.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-013
