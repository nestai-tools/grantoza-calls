# Q-016 — Miejscowość

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Dla osoby fizycznej adres wykonywania działalności, dla osoby prawnej adres siedziby, zgodny z rejestrem. Nie zastępować adresem zamieszkania, gdy jest inny. Tekst źródła nie określa słownika miejscowości.

Warunek: zawsze. Typ: tekst. Limit znaków: nie wskazano.

Wybory: nie dotyczy.

Wymagania: REQ-002, REQ-013
