# Q-010 — Wielkość przedsiębiorstwa

[Formularz / szablon odpowiedzi](../form.md) · [Wymagania](../../../02-analysis/requirements.md)

## Wskazówki

Wybór pojedynczy na dzień złożenia. Ustalenie statusu obejmuje właściwe dane skumulowane przedsiębiorstw partnerskich i powiązanych według Załącznika I rozporządzenia 651/2014. Deklaracja nie zastępuje weryfikacji MŚP, ponawianej przed umową.

Warunek: zawsze. Typ: wybor. Limit znaków: nie wskazano.

Wybory: mikro, mały, średni.

Wymagania: REQ-001
